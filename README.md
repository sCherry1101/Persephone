# Persephone [WIP!!!]

## Overview 

Persephone is a lightwieght, customizable terminal-based Spotify client written in C++.

---

## How to run?

### Clone repo:
 ```git clone https://github.com/sCherry1101/Persephone.git```

### Navigate to the project:
 ```cd Persephone```

### Run:
**A helper script is included so you don't have to repeatedly type the CMake commands:**

*Execute once:*
 ``chmod +x run.sh``

*After that run:*
 ``./run.sh``
