# Contribution.md

## Contributions are welcome!!!! Here are following things to know before contributing :

- Git commit format :
    ``header: body``

Some commonly used headers are ``add:`` , ``fix:`` , ``update:`` ``pr:`` with brief note as ``body``!

- File structure : 

1. The folders and file names are self explanatory but if still confused feel free to read ``context.md``!

2. For making new files/folders make sure the name should be related to the code inside it

3. Each file should NOT exceed 200 lines

- What can you contribute too?

1. New themes
2. New commands 
3. New feature which is not part of the project

- Extra : If the contribution idea is a new idea and requires lot of changes make issue beforehand then the issue will be reviewed for further PR and merged accordingly
